Featured project

City Explorer

A deployed full-stack trip-planning application that lets users search cities, discover nearby places, build an itinerary and generate an optimised walking route.

  • Built with React, TypeScript, Vite, Leaflet, Node.js and Express.
  • Integrated Geoapify for place discovery and geocoding, and OpenRouteService for walking routes and distance matrices.
  • Implemented nearest-neighbour route construction with 2-opt improvement for stop-order optimisation.
  • Added Zod runtime validation, centralised error handling, API timeouts, rate limiting and structured Pino logging.
  • Added a 16-test Vitest/Supertest suite, GitHub Actions CI and a Dockerised backend deployed on Render, with the frontend deployed on Vercel.

Final-Year Dissertation | Accessibility Research & Data Analysis

An independent mixed-methods research project investigating how accessibility features affect user interaction, performance and usability in digital games.

  • Independently designed and carried out a structured study combining quantitative performance data with questionnaires, observations and interviews.
  • Applied statistical testing, comparative analysis and correlation analysis to identify meaningful differences and behavioural trends.
  • Analysed both quantitative and qualitative evidence to build a broader understanding of how users interacted with the system.
  • Found that the accessibility features tested reduced input demand by approximately 85%, while improving several usability and performance measures.
  • Translated the findings into clear, evidence-based conclusions, demonstrating independent research, analytical thinking and user-centred problem solving.
